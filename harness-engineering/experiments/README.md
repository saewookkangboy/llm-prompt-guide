# experiments/ — 루프 엔지니어링 기록

디렉터리 하나가 실험 하나. 이름은 `<YYYY-MM>-<요약>`.

```
2026-08-router-ab/
├── hypothesis.md   실험 전에 쓴다
└── result.md       실험 후에 쓴다
```

## 규칙

1. **가설을 먼저 쓴다** — 판정 기준을 결과 본 뒤에 정하면 모든 실험이 성공한다
2. **한 번에 하나만 바꾼다** — 두 개를 바꾸면 무엇이 효과였는지 알 수 없다
3. **실패도 남긴다** — 폐기 기록이 없으면 6개월 뒤 같은 실험을 반복한다
4. **실패 케이스는 평가셋으로** — `evals/datasets/regression/`

## 실험 시작점

아이디어가 아니라 **지난주 트레이스의 실패**에서 시작한다.
아이디어에서 출발한 실험은 대개 이미 잘 되는 것을 조금 더 잘 만든다.
