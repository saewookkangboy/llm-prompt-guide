# ADR-0002. 평가 통과를 머지 조건으로 강제한다

- 상태: 채택
- 날짜: 2026-08-18

## 맥락

프롬프트 변경은 diff가 작아 리뷰에서 통과하기 쉽지만, 영향은 전역적이다.
"톤을 부드럽게" 한 줄이 구조화 출력의 필드 누락을 유발한 사례가 2건 있었다.

## 결정

`harness/prompts/**`, `harness/**` 변경 PR은 `make eval-smoke` 통과를 필수로 한다.
배포는 `make eval-full`을 거치며 회귀 스위트는 100%를 요구한다.

## 결과

**좋아지는 것**: 회귀 재발 차단, 변경 근거가 점수로 남음.

**나빠지는 것**: PR당 3~5분, 건당 약 $0.4의 평가 비용. 저지 모델 호출이므로
평가셋이 커질수록 비싸진다. 스모크는 20건으로 제한하고 전체는 배포 시에만 돌린다.

## 재검토 조건

평가 비용이 월 $300을 넘거나, 스모크 실행이 10분을 넘으면 샘플링 전략을 재설계한다.
