# reports/ — 평가 결과

실행 산출물이라 커밋하지 않는다 (`.gitignore`). 형식만 여기 정의한다.

```
reports/
├── 2026-08-25T09-14_smoke_a3f21.json     기계 판독용 원본
├── 2026-08-25T09-14_smoke_a3f21.md       사람이 읽는 요약
└── judge-calibration.md                   저지-사람 상관 추이 (이 파일은 커밋)
```

## 요약에 반드시 들어가는 것

- 기준선 대비 **변화량** (절대 점수만으로는 판단할 수 없다)
- 실패 케이스 ID 전체 목록
- 실패 **유형별** 분포
- 비용·지연

점수가 올랐는데 비용이 3배가 됐다면 그것은 개선이 아니라 트레이드오프다.
