# 외부 툴 장애

## 증상

`atlas.tool_denials` 또는 어댑터 오류율 급증, 실행이 `tool_unavailable`로 종료.

## 즉시 조치

1. 어느 툴인지 확인
   ```bash
   python scripts/replay_trace.py --since 1h --group-by tool_name --status error
   ```
2. 해당 툴을 쓰는 워크플로를 확인하고, 대체 경로가 있으면 전환한다
3. 대체 경로가 없으면 그 워크플로를 일시 비활성화한다. 툴 없이 돌게 두면
   모델이 빈칸을 추측으로 채운다 — 장애가 품질 사고로 번진다.

## 원인 확인

- 프로바이더 상태 페이지
- 인증·쿼터 만료 여부
- 최근 어댑터 변경 이력

## 복구

프로바이더 복구 후 스모크로 확인하고 워크플로를 되살린다.

## 사후 조치

어댑터의 실패 메시지가 모델에게 다음 행동을 안내했는지 검토한다.
"500 Internal Error"만 돌려줬다면 메시지를 고친다.
