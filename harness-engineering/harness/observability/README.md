# observability/ — 관측

**넣는 것**: 트레이스 수집, 비용 집계, 메트릭 방출
**넣지 않는 것**: 비즈니스 로직 분기. 관측이 동작을 바꾸면 관측이 아니다.

## 트레이스에 반드시 들어가는 것

- 실행 ID·워크플로·프롬프트 **버전**
- 각 단계의 입력 토큰·출력 토큰·지연·모델
- 툴 호출: 이름·인자·결과 요약·거부된 시도
- 절삭된 컨텍스트 항목 ID
- 가드레일 개입 내역
- 종료 사유

프롬프트 버전이 없으면 "지난주 그 결과"를 재현할 수 없다.
거부된 툴 호출 시도를 남기지 않으면 권한 정책이 맞는지 검증할 수 없다.

## 개선 루프와의 연결

`scripts/replay_trace.py`가 트레이스를 평가 케이스로 변환한다.
실패한 실행은 이 경로로 `evals/datasets/regression/`에 들어간다.
관측의 목적은 대시보드가 아니라 평가셋을 살찌우는 것이다.
