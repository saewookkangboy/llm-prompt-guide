# context/ — 컨텍스트 조립

**넣는 것**: 검색·랭킹, 메모리 요약, 토큰 예산 배분, 컨텍스트 직렬화
**넣지 않는 것**: 모델 호출, 툴 실행, 프롬프트 문자열

## 파일

| 파일 | 책임 |
|---|---|
| `assembler.py` | 조각들을 하나의 컨텍스트 번들로 조립 (이 레이어의 진입점) |
| `retrieval.py` | 문서 검색과 랭킹, 출처 태깅 |
| `memory.py` | 3계층 메모리 읽기·쓰기 |
| `budget.py` | 토큰 예산 배분과 절삭 순서 (단일 구현체) |

## 규칙

- 모든 청크는 출처 ID를 달고 들어간다. 출처 없는 근거는 검증할 수 없다.
- 절삭은 `budget.py`를 통해서만. 다른 곳에서 문자열을 자르지 않는다.
- 검색 0건은 빈 컨텍스트로 진행하지 않고 `EmptyContextError`를 던진다.
