# config/ — 설정

모두가 읽고 아무도 런타임에 수정하지 않는다.

| 파일 | 내용 |
|---|---|
| `models.yaml` | 모델 티어·단가·컨텍스트 한도 |
| `defaults.yaml` | 라우팅 규칙, 루프·예산 기본값 |
| `environments/` | dev·stage·prod 오버라이드 |

## 규칙

- 모델명은 코드 어디에도 하드코딩하지 않는다. 티어 이름(`fast`/`balanced`/`deep`)으로 참조한다
- 비밀값은 여기 두지 않는다. `.env`와 시크릿 매니저로
- 환경 파일은 **차이만** 적는다. 전체 복사본을 3개 두면 반드시 어긋난다
