# adapters/ — 툴 구현

어댑터는 스키마 하나당 하나. 규칙:

- 재시도는 어댑터 안에서 (지수 백오프, 최대 3회). 오케스트레이션이 재시도를 알 필요는 없다
- 외부 응답은 그대로 반환하지 않고 정규화한다 — 프로바이더 교체 시 프롬프트가 안 바뀌게
- 예외는 `ToolError`로 감싼다. 원본 스택은 트레이스에만 남기고 모델에게는 요약만 준다
- 실패 메시지는 모델이 다음 행동을 고를 수 있게 쓴다. "500 Internal Error"가 아니라
  "지표 조회 실패: 캠페인 ID를 찾을 수 없음. ID를 확인하거나 다른 기간으로 재시도"
